# AngularJS Project

This is an AngularJS project. Follow the steps below to set it up and run it on your local machine.

## Prerequisites
Make sure you have the following installed on your system:
- [Node.js](https://nodejs.org/) (Recommended LTS version)
- [npm](https://www.npmjs.com/)
- A live server extension or tool (e.g., VS Code Live Server Extension)

## Installation & Setup

1. **Clone the repository**
   ```sh
   git clone https://github.com/Chief16/ECommerce-AngularJS.git
   cd ECommerce-AngularJS
   ```

2. **Install dependencies**
   ```sh
   npm install
   ```

3. **Run the development server**
   ```sh
   npm run dev
   ```

4. **Open the project in a browser**
   - Use a live server extension in your editor and open `index.html`
   - Or open `index.html` manually in a browser
